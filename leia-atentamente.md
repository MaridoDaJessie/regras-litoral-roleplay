# LEIA ATENTAMENTE

Todo jogador deve conhecer as regras da **Litoral Roleplay**.

{% hint style="warning" %}
O desconhecimento das regras não elimina a responsabilidade sobre infrações cometidas.
{% endhint %}

## Princípios gerais

1. Conheça as regras.
2. Priorize o Roleplay.
3. Separe IC de OOC.
4. Respeite jogadores e administração.
5. Guarde provas quando uma denúncia for necessária.
6. Evite interromper ações para discutir regras no meio da situação.
