## Bem-vindo à Litoral Roleplay

Este é o portal oficial de regras da **Litoral Roleplay**.

Antes de iniciar sua jornada na cidade, leia atentamente todas as regras. O conhecimento das normas é responsabilidade de cada jogador.

{% hint style="info" %}
As regras podem ser atualizadas. Consulte este portal regularmente.
{% endhint %}
