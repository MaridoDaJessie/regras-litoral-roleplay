# Guia de instalação no GitBook

Envie **o conteúdo desta pasta para a raiz** do repositório.

Na raiz do GitHub devem aparecer diretamente:

- `README.md`
- `SUMMARY.md`
- `.gitbook/`
- `administracao/`
- `acoes/`
- `organizacoes/`
- `regras-de-roleplay/`
- `regras-gerais/`
- `servicos-publicos/`
- `veiculos/`

Depois conecte o repositório ao GitBook pelo Git Sync.
